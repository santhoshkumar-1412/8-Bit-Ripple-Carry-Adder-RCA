## 1. Project Overview

This project presents the RTL design and functional verification of an **8-Bit Ripple Carry Adder (RCA)** using Verilog Hardware Description Language (HDL).

A Ripple Carry Adder is a fundamental combinational arithmetic circuit used to perform binary addition. It consists of multiple Full Adders connected in series, where the carry output of each Full Adder is propagated to the carry input of the next stage.

In this implementation, eight Full Adders are cascaded to perform 8-bit binary addition.

The design accepts two 8-bit binary operands and one carry-in input, producing an 8-bit sum and a final carry-out.

The RTL implementation is simulated using **Synopsys VCS**, while waveform visualization and signal-level debugging are performed using **Synopsys Verdi**.

## 3. Design Methodology

The Ripple Carry Adder performs binary addition by connecting multiple Full Adder circuits in series.

The carry generated by one stage becomes the carry input for the next stage. This process continues until the final carry output is generated.

### 3.1 Full Adder Design

The Full Adder is the basic building block of the Ripple Carry Adder.

It performs the addition of three single-bit inputs:

- A: First input bit
- B: Second input bit
- Cin: Carry input

**Boolean Expressions:**

Sum:
```text
S = A XOR B XOR Cin
```

Carry:
```text
Cout = (A AND B) OR (A AND Cin) OR (B AND Cin)
```

### 3.2 Ripple Carry Adder Architecture

An 8-bit Ripple Carry Adder is constructed using eight Full Adder instances connected in series.

Each Full Adder performs the addition of the corresponding bits of operands A and B along with the carry from the previous stage.

**Sum Equation:**
```text
S[i] = A[i] XOR B[i] XOR C[i]
```

**Carry Equation:**
```text
C[i+1] = (A[i] AND B[i]) OR (A[i] AND C[i]) OR (B[i] AND C[i])
```

The carry propagation follows this sequence:

```text
Cin -> FA0 -> FA1 -> FA2 -> FA3
    -> FA4 -> FA5 -> FA6 -> FA7 -> Cout
```

### 3.3 Overall Addition Equation

The complete 8-bit addition operation is represented as:

```text
Result = A + B + Cin
```

The final 9-bit result is represented as:

```text
Result = {Cout, S}
```

The output consists of an 8-bit sum and a 1-bit carry-out.

### 3.4 Working Principle

1. The two 8-bit input operands are applied to the Full Adder stages.
2. The first Full Adder receives the external carry-in.
3. Each Full Adder generates a sum and carry output.
4. The carry output is propagated to the next Full Adder.
5. The final Full Adder generates the most significant sum bit and the final carry-out.

This process performs complete 8-bit binary addition.

## 4. RTL Module Architecture

The project consists of the following Verilog modules:

| Module | Functionality |
|---|---|
| `fa` | Implements Full Adder logic |
| `bit4_rca` | Implements an 8-bit Ripple Carry Adder using eight Full Adders |
| `bitrca8_tb` | Testbench for functional verification |

### 4.1 Full Adder Module

The Full Adder generates Sum and Carry outputs using XOR, AND and OR logic.

### 4.2 8-Bit Ripple Carry Adder Module

The RCA module instantiates eight Full Adders.

The carry output of each stage is connected to the carry input of the next stage using intermediate carry signals:

```text
c1, c2, c3, c4, c5, c6, c7
```

The final Full Adder generates the 8-bit sum and final carry-out.

## 6. Functional Verification

A Verilog testbench is developed to verify the functionality of the 8-bit Ripple Carry Adder.

The testbench applies six different combinations of input operands and carry-in values at 10 ns intervals.

The simulation results are observed using the `$monitor` system task.

| TC2 | 88 | 174 | 1 | 7 | 1 |
| TC3 | 255 | 1 | 0 | 0 | 1 |
| TC4 | 170 | 85 | 1 | 0 | 1 |
| TC5 | 15 | 1 | 0 | 16 | 0 |
| TC6 | 240 | 15 | 1 | 0 | 1 |

## 7. Simulation Environment

The design is simulated using Synopsys VCS, and waveform analysis is performed using Synopsys Verdi.

### 7.1 Simulation Workflow

```text
       Verilog RTL Design
               |
               v
        Verilog Testbench
               |
               v
         Synopsys VCS
               |
               v
         RTL Simulation
               |
               v
         VCD / FSDB File
               |
               v
        Synopsys Verdi
               |
               v
        Waveform Analysis
```

### 7.2 VCS Compilation

Compile the RTL source and testbench using:

```bash
vcs -full64 -debug_access+all \
bitrca8.v \
bitrca8_tb.v \
-o simv
```

### 7.3 Execute Simulation

Run the compiled simulation executable:

```bash
./simv
```

The testbench executes six test cases and displays the corresponding sum and carry outputs.

### 7.4 VCD Waveform Generation

The testbench generates a VCD waveform database using:

```verilog
initial
begin
    $dumpfile("bitrca8.vcd");
    $dumpvars(0, bitrca8_tb);
end
```

This enables signal transitions to be recorded during simulation.

### 7.5 Open Waveform in Synopsys Verdi

The generated VCD file can be opened using:

```bash
verdi -vcd bitrca8.vcd &
```

Alternatively, if an FSDB waveform is generated using the appropriate Verdi PLI integration:

```bash
verdi -ssf inter.fsdb &
```
